# Tejas C. Waghmare — Data Analyst Portfolio Website

A cinematic, modern, high-contrast Data Analyst & Business Intelligence portfolio website built with Vanilla HTML5, CSS3, and JavaScript, designed to match the reference theme with matte graphite cards, electric yellow accents, and an integrated 240-frame scroll-based background animation.

---

## 🚀 Quick Start / Local Preview

To launch the portfolio locally:

```bash
# In the project directory:
python -m http.server 8080
```

Then open your browser to **[http://localhost:8080](http://localhost:8080)**.

---

## 🎨 Design & Visual Identity

- **Theme**: Matte Graphite (`#131417` / `#1f2025`) with Electric Yellow accents (`#F5E025`).
- **Typography**: Plus Jakarta Sans (Headings), Inter (Body copy), JetBrains Mono (Telemetry & Metrics).
- **Background Animation**: HTML5 Canvas rendering 240 original frames with linear interpolation (lerp) scrubbing dynamically as the page is scrolled.
- **Bento Grid**: 9 structured modular sections with rounded cards, status badges, and interactive modals.

---

4. **Skills**: Categorized bento cards covering BI & Visualization, Data Modeling, Programming & SQL, and Cloud/Fabric ecosystem.

7. **Education**: B.Tech Mechanical Engineering from Bajaj Institute of Technology (CGPA 8.04), HSC (IT), SSC.
8. **Hobbies**: Data Storytelling & Kaggle, Automotive Telemetry & IoT, Chess & Strategy, Next-Gen AI.
9. **Contact**: Direct contact channels (Email, WhatsApp/Phone, Location), social profile pills (LinkedIn, GitHub, Credly), and an interactive contact form with instant email client trigger.
